# 세계 화제 레이더 — 매일 지시서

전 세계에서 지금 뭐가 화제인지 모아 텔레그램으로 보낸다. **vidiq를 쓰지 않는다.** 크레딧 0.

사용자는 실행 중에 없다. 질문하지 말고 진행한다.
**이건 매일 도는 조용한 루틴이다.** 장황한 보고는 필요 없다.

---

## 1. 수집

저장소를 pull 하고 그냥 돌린다. 소스 정의와 파싱은 전부 스크립트 안에 있다.

```bash
python3 radar/collect.py
```

`--fast` 를 붙이지 않는다. 레딧까지 다 받는다. 피드 사이 60초 대기가 있어 2~3분 걸리는 게 정상이다.

결과는 두 개다.

- `radar/data/YYYY-MM-DD.json` — 원자료
- `radar/digest/YYYY-MM-DD.md` — 읽을 것

**소스 몇 곳이 실패해도 그냥 넘어간다.** 스크립트가 알아서 건너뛰고 다이제스트 끝에 실패 목록을 남긴다. 17곳 중 서넛 빠지는 건 정상이다. 다만 **절반 이상 실패하면** 네트워크나 허용 도메인 문제이니 보고에 크게 적는다.

## 2. 커밋

```bash
git config user.email "noreply@anthropic.com"
git config user.name "TEO radar"
git add radar/data radar/digest
git commit -m "레이더 ($TODAY)"
git push
```

**누적이 핵심이다.** `radar/data/` 가 쌓여야 "며칠 연속 잡히는 것"과 "하루 반짝"이 갈린다. 지우지 않는다.

개인 토큰을 쓰지 마라. GitHub 쓰기는 Claude GitHub App 이 담당한다.

## 3. 텔레그램 보고 — 여기가 이 루틴의 전부다

### 어느 봇으로 보내나

**`$RADAR_BOT_TOKEN` 이 있으면 그걸 쓴다.** 없을 때만 `$TELEGRAM_BOT_TOKEN` 으로 떨어진다.
`chat_id` 는 어느 쪽이든 `$TELEGRAM_CHAT_ID` 를 그대로 쓴다 — 텔레그램 1:1 대화는 봇이 달라도 chat_id 가 같다.

레이더는 리서치 봇으로 보낸다. 쇼츠박스 카드뉴스와 같은 방에 쌓이면 나중에 섞여서 못 읽는다.

### 제목만 나열하지 마라

**이게 제일 중요하다.** 다이제스트를 그대로 옮기면 읽는 사람은 아무것도 못 얻는다.
`Cloudflare OS — 기술+신제품, 3개 소스` 는 정보가 아니다. 그게 뭔지, 왜 떴는지, 그래서 뭔지를 **네가 써야 한다.**

지켜야 할 것 다섯.

1. **영어는 전부 우리말로.** 고유명사(제품명·인명)만 원문을 남긴다
2. **왜 떴는지 한 줄로.** 다이제스트의 원제목들을 읽으면 대개 알 수 있다. 그래도 모르겠으면 WebSearch 로 한 번 찾아본다. **지어내지 마라** — 모르면 "이유는 확인 못 했다"고 쓴다
3. **그래서 뭔지, 진짜 인사이트를 한 줄.** "신호입니다", "눈에 띕니다" 같은 말로 뭉개지 마라. 이게 왜 중요한지, 무슨 함의가 있는지, 이어질 다음 일이 뭔지를 구체적으로 써라. "재생에너지 정책을 정책이 아니라 돈으로 뒤집었다" 정도의 해석이 최소선이다. 억지로 사업 아이디어를 붙이지는 마라 — 붙일 게 없으면 안 붙인다
4. **출처는 매체·사이트 실명으로.** "3개 소스"처럼 숫자만 적지 마라. `출처: AMD 뉴스룸, CNBC, The Register` 처럼 어디서 나온 얘기인지 각 항목 끝에 적는다. 다이제스트의 대괄호 태그(`[해커뉴스]`, `[Techmeme]` 등)와 WebSearch 로 찾은 실제 언론사명을 합쳐 쓴다
5. **숫자·팩트는 구체적으로.** "많이 모였다"가 아니라 "282명 댓글", "5억 달러", "74세" 처럼 다이제스트나 검색에 있는 실제 수치를 그대로 쓴다

나쁜 예 (지금 이러고 있다):

```
새로 뜬 것
  Cloudflare OS    기술+신제품, 3개 소스
  독일 공항 드론      뉴스+서구커뮤, 3개 소스
```

이것도 나쁜 예 (숫자만 세고 출처가 없다, 인사이트가 "신호입니다"로 뭉개진다):

```
Cloudflare OS
클라우드플레어가 브라우저에서 도는 운영체제를 오픈소스로 풀었습니다.
AI 에이전트가 사람 대신 앱을 조작하게 하려는 구도예요.
개발자 쪽 세 곳에 동시에 떴습니다.
```

좋은 예:

```
Cloudflare OS
클라우드플레어가 브라우저에서 도는 운영체제를 오픈소스로 풀었습니다.
AI 에이전트가 사람 대신 앱을 조작하게 하려는 구도예요. 지금은 에이전트가
크롬을 통째로 켜서 화면을 흉내내는 식이라 느리고 비싼데, 이게 자리잡으면
그 비용 구조가 통째로 바뀝니다.
출처: 해커뉴스, Techmeme, ProductHunt (개발자 3곳 동시)

독일 공항 폭발물 드론
폭발물을 실은 드론이 독일 공항에서 발견됐고, 당국이 "새로운 차원"이라고
했습니다. 러시아 하이브리드 공격 의심이 나오는 터라, 유럽 전역 공항이
드론 탐지 장비를 서둘러 들일 명분이 될 만합니다.
출처: BBC, 로이터 (뉴스 2곳 + 레딧 r/worldnews)
```

### 뭐가 값어치 있고 뭐가 아닌가

**뉴스 요약은 값어치가 없다.** 독일 공항 드론, 호르무즈 해협, 우크라이나 — 이런 건 아무 데서나 본다. 이걸 옮겨 적으면 읽는 사람 시간만 뺏는다.

값어치는 **남들이 아직 모르는 것**에 있다. 그래서 다이제스트가 세 칸으로 나뉜다.

| 칸 | 뜻 | 비중 |
| --- | --- | --- |
| 아직 언론에 안 나온 것 | 커뮤니티·개발자·신제품엔 떴는데 뉴스는 아직 | **제일 크게** |
| 해외만 시끄럽고 한국은 조용한 것 | 국내에 아직 안 들어옴 | 크게 |
| 교차엔 안 걸렸지만 눈여겨볼 것 | 한 곳뿐이어도 아이템 냄새가 나는 것 | **크게** |
| 이미 퍼진 것 | 뉴스에 나옴 | 맨 뒤 한 줄, 또는 생략 |

**"이미 퍼진 것"은 웬만하면 빼라.** 넣더라도 맨 아래 한 줄로 압축한다. 거기 있으면 이미 늦은 것이다.

### 형식

```
[레이더] 8/7 금

━ 아직 언론엔 없다

(선행 항목. 각각 제목 + 두세 줄 설명. 없으면 "오늘은 없습니다" 한 줄)

━ 해외만 시끄럽다

(국내 미상륙 항목)

━ 돈 냄새

(/biz/·해커뉴스·ProductHunt 에서 고른 것 2~3개.
 왜 아이템 냄새가 나는지 반드시 한 줄 붙인다. 그냥 옮기면 의미 없다)

━ 세계가 찾아본 것

(위키백과 상위 2~3개. 왜 찾아보는지)

━ 한국

(구글트렌드 한국 + 디시·뽐뿌. 2~3개)

전문: github.com/teoteobak-commits/earlycatch/blob/master/radar/digest/{날짜}.md
```

빈 칸은 제목째 뺀다.

### "돈 냄새" 칸을 제대로 쓰는 법

이게 이 보고서의 핵심이다. 예를 들어 오늘 `/biz/` 에 이런 게 있었다.

> How do we profit from men choosing to have no kids nor getting married anymore?

이걸 그대로 옮기면 안 된다. 이렇게 쓴다.

```
결혼·출산 안 하는 남자들로 뭘 팔까
4chan 돈 얘기판에서 282명이 붙은 스레드입니다. 1인 가구가 늘면
뭐가 팔리느냐를 놓고 갑론을박이 오갔어요. 인구 얘기를 거대담론이
아니라 "그래서 뭘 파느냐"로 놓고 보는 시각이라 눈에 걸렸습니다.
```

**억지로 붙이지는 마라.** 오늘 붙일 게 없으면 이 칸을 통째로 뺀다. 없는 걸 지어내면 다음 날부터 안 읽힌다.

### 길이

3000자 안쪽(한도 4096). 넘치면 **항목 수를 줄이지 설명을 줄이지 않는다.** 설명 없는 목록 열 개보다 제대로 쓴 세 개가 낫다.

```bash
curl -s -X POST "https://api.telegram.org/bot$TOKEN/sendMessage"   -F chat_id="$TELEGRAM_CHAT_ID" -F text="<내용>"
```

응답이 `{"ok":true` 인지 확인한다. 실패하면 보고에 에러 원문을 남긴다.

## 4. 최종 보고

한두 줄이면 된다. 예: `17곳 중 15곳 성공, 226건, 교차 신호 13개. 새로 뜬 것 5개.`
실패한 소스가 있으면 이름만 나열한다.

## 주의사항

- **vidiq 를 절대 쓰지 않는다.** 크레딧은 K-한류(kpop_kit_factory) 몫이다.
- 커뮤니티 원문을 퍼오지 않는다. **제목만** 센다. 무엇이 화제인지 세는 용도지 재배포가 아니다.
- 레딧 데이터 이용약관은 상업적 이용을 제한한다. 지금은 개인 정찰용이다.
- 환경변수 값(토큰)을 로그나 보고에 출력하지 않는다.
