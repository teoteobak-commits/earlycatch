# 세계 화제 레이더

지금 전 세계에서 뭐가 화제인지 모으는 도구. **vidiq를 쓰지 않는다** — 전부 무료 공개 소스다.

```bash
python radar/collect.py          # 전체 (레딧 포함, 2분쯤)
python radar/collect.py --fast   # 레딧 빼고 (30초)
python radar/collect.py --list   # 소스 목록
```

결과는 `radar/digest/YYYY-MM-DD.md` 에 읽을 수 있게, `radar/data/YYYY-MM-DD.json` 에 원자료로 쌓인다.

## 소스 21곳, 6계열

| 계열 | 소스 | 뭘 보여주나 |
| --- | --- | --- |
| 관심 | 위키백과 조회수 | 전 세계가 지금 **찾아보는** 것 |
| 검색 | 구글 트렌드 미국·한국·영국·일본 | 나라별 급상승 검색어 + 대략 검색량 |
| 뉴스 | BBC 월드, 구글뉴스 세계·한국 | 주류 매체가 다루는 것 |
| 기술 | 해커뉴스, Techmeme | 만드는 사람들이 보는 것 |
| 신제품 | ProductHunt | 오늘 나온 것 |
| 커뮤니티(서구) | 레딧 3종, 4chan /g/ /biz/ /v/, Lemmy | 익명·투표 기반. 화제가 제일 먼저 뜨는 곳 |
| 커뮤니티(한국) | 디시 실베, 에펨코리아, 뽐뿌 | 국내에서 지금 도는 것 |

## 핵심은 교차 확인이다

한 소스에만 있으면 그 바닥 얘기다. **성격이 다른 계열에 동시에 걸릴 때만** 신호로 친다.

구글뉴스는 BBC 기사를 실어 나르므로 그 둘이 겹치는 건 확인이 아니라 같은 기사를 두 번 센 것이다. 그래서 소스가 아니라 **계열**을 센다. 이 규칙 하나로 신호가 12개에서 4개로 줄었고, 남은 4개가 진짜였다.

매체 이름(BBC, Reuters, 연합뉴스…)은 제목 꼬리표라 화제에서 제외한다.

## 매번 다 성공하지는 않는다

2026-08-06 클라우드 첫 실행에서 21곳 중 18곳 성공, 241건. 실패한 둘은 이랬다.

- **에펨코리아 430** — 봇 차단. 데이터센터 IP를 막는다. 가정용 IP(로컬)에서는 되는데 클라우드에서는 걸린다. 한국 커뮤니티가 여기 하나에만 기대지 않도록 뽐뿌를 추가해뒀다
- **레딧 429** — 레이트 리밋. 클라우드는 공용 IP라 남과 한도를 나눠 쓴다. 이제 429 가 나면 90초 기다렸다 한 번 더 시도한다

**서넛 빠지는 건 정상이다.** 스크립트가 알아서 건너뛰고 다이제스트 끝에 실패 목록을 남긴다. 절반 이상 실패하면 그때가 네트워크나 허용 도메인 문제다.

## 알아둘 것

**레딧은 느리다.** RSS는 인증 없이 열리지만(JSON API는 403) 짧은 간격으로 때리면 429가 난다. 피드 사이에 60초를 둔다. 급하면 `--fast`.

**레딧 데이터 이용약관은 상업적 이용을 제한한다.** 개인이 정찰하는 용도는 괜찮지만 가공해서 파는 건 다른 얘기다.

**위키백과 조회수는 이틀 전 데이터다.** 집계에 시간이 걸린다. 대신 가장 정직한 관심 지표다 — 검색은 낚시 제목에 흔들리지만 문서를 찾아 읽는 건 진짜 궁금해야 한다.

**GDELT는 아직 안 붙였다.** 전 세계 뉴스 이벤트 DB인데 레이트 리밋에 걸렸다. 다시 시도해볼 가치는 있다.

## 하루치로는 부족하다
