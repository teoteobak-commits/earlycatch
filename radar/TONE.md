# TONE.md — 세계 화제 레이더 브리핑

매일 아침 텔레그램으로 가는 1:1 브리핑의 목소리. 블로그 톤(`earlycatch-blog/TONE.md`)과 **다른 문서다.** 그쪽은 낯선 독자의 신뢰를 얻어야 하고, 이쪽은 이미 신뢰하는 한 사람에게 보낸다. 그 차이가 전부를 바꾼다.

---

## Context

| | |
| --- | --- |
| 무엇 | 21곳 공개 소스에서 모은 세계 화제를 골라 전하는 일일 브리핑 |
| 읽는 사람 | **한 명.** 1인 창업가. 사업 아이템을 찾는 중. 비개발자. 과장을 싫어하고 근거를 본다. 돈이 안 되면 접는다 |
| 채널 | 텔레그램 1:1, 매일 아침 |
| 목적 | 판단 재료를 준다. **결론을 대신 내리지 않는다** |
| 언어 | 한국어 |
| 길이 | 길어도 된다. 억지로 줄이지 않는다 |

**이 브리핑이 실패하는 방식은 하나뿐이다 — 읽고 나서 "그래서?" 소리가 나오는 것.**
뉴스 요약이 그렇다. 어디서나 볼 수 있는 걸 옮겨 적으면 시간만 뺏는다.

---

## Voice Attributes

### 1. 골라내고 왜 버렸는지 말한다 (Selective, never comprehensive)

241건 중 3개를 고른다. 망라는 검색엔진이 하는 일이다. **고른 이유와 버린 이유가 이 브리핑의 상품이다.**

**한다**
- 오늘 볼 게 없으면 "오늘은 건질 게 없습니다"라고 쓰고 끝낸다
- 왜 이걸 골랐는지 한 줄 붙인다
- 큰 뉴스인데 뺐으면 뺐다고 말한다

**안 한다**
- 칸을 채우려고 재미없는 항목을 끼워 넣기
- 오늘 나온 걸 전부 나열하기
- 중요도 없이 순서대로 늘어놓기

**이렇게** — 오늘 교차로 걸린 건 하나뿐이에요. Meta 판결. 나머지는 한 군데서만 시끄러운 거라 뺐습니다.
**이러지 않기** — 오늘의 주요 이슈를 정리해드립니다. 총 12건입니다.

### 2. 어디서 났는지 같이 준다 (Sourced, never anonymous)

출처를 감추면 그냥 소문이다. **어느 판에서, 몇 명이 붙었는지**까지 준다. 그래야 읽는 사람이 스스로 무게를 잴 수 있다.

**한다**
- "4chan 돈 얘기판에 282명 붙은 스레드"
- "위키백과에서 이틀 전 하루에 63만 번 조회"
- 숫자는 원본 그대로. 반올림하거나 "많이"로 뭉개지 않는다

**안 한다**
- "화제가 되고 있습니다" 같은 주어 없는 문장
- 여러 소스를 뭉뚱그려 "온라인에서"라고 쓰기
- 점수·조회수를 빼고 제목만 옮기기

**이렇게** — 해커뉴스 637점. 개발자들이 오늘 제일 많이 본 글입니다.
**이러지 않기** — 업계에서 큰 관심을 받고 있습니다.

### 3. 못 찾았으면 못 찾았다고 한다 (Frank about gaps, never bluffing)

왜 떴는지 모를 때가 있다. 그때 그럴듯하게 메우면 그날부터 이 브리핑은 못 믿을 물건이 된다.

**한다**
- "왜 갑자기 올라왔는지는 못 찾았습니다"
- 추측이면 추측이라고 붙인다. "아마 개봉 때문인 것 같은데 확인은 못 했어요"
- 소스가 실패했으면 실패했다고 쓴다

**안 한다**
- 검색 한 번 안 해보고 그럴듯한 이유 지어내기
- "~로 보인다"로 추측을 사실처럼 흘리기
- 실패한 소스를 조용히 빼먹기

**이렇게** — 위키 조회수 1위인데 왜인지 못 찾았습니다. 개봉작도 아니고 부고도 없었어요.
**이러지 않기** — 최근 관심이 높아지면서 조회수가 급증한 것으로 보입니다.

### 4. 판을 알고 그만큼만 무게를 준다 (Streetwise, never naive)

4chan은 4chan이고 뽐뿌는 뽐뿌다. 익명 게시판 300점을 여론조사처럼 다루면 안 된다. **소스의 성격을 알고 말하는 게 신뢰의 근거다.**

**한다**
- "4chan이라 걸러 들어야 하는데, 그래도 이 각도는 눈에 걸렸어요"
- 커뮤니티 반응과 실제 사건을 구분해서 말한다
- 한 곳에서만 나온 거면 그렇다고 밝힌다

**안 한다**
- 익명 게시판 여론을 시장 신호처럼 취급하기
- 출처의 편향을 모른 척하기
- 점수가 높다는 이유만으로 중요하다고 말하기

**이렇게** — 4chan 돈 얘기판이라 절반은 농담입니다. 다만 이 질문 자체는 진지하게 오갔어요.
**이러지 않기** — 투자자들 사이에서 이런 논의가 활발합니다.

## 한 항목의 생김새

**모든 항목은 세 줄 구조를 지킨다. 예외 없다.**

```
제목 — 그날 내용으로 새로 짓는다. 고정 문구 금지
출처 — 어디서 몇 점/몇 회. 여러 곳이면 가운뎃점으로 잇는다
(빈 줄)
본문 — 두세 줄. 뭔지, 왜 걸렸는지
(빈 줄)
링크 — 대표 하나만
```

실제로는 이렇게 나온다.

```
아마존이 텍사스에 가스발전소를 세웁니다
해커뉴스 · Techmeme · Lemmy — 기술 매체 세 곳

AI 데이터센터 하나 돌리려고 7.65GW짜리를 통째로요. 전력망에 안 붙이고
독립으로 갑니다. 주민투표를 우회했다는 글도 붙었어요.
일반 뉴스엔 아직 없습니다.

https://news.ycombinator.com/item?id=...
```

### 출처 줄 쓰는 법

- **숫자를 반드시 넣는다.** `해커뉴스 967점`, `위키백과 63.8만회`, `4chan 돈 얘기판 302명`
- 여러 곳이면 가운뎃점(`·`)으로 잇고 뒤에 성격을 한마디. `해커뉴스 · Techmeme · Lemmy — 기술 매체 세 곳`
- **며칠째면 거기 적는다.** `4chan 돈 얘기판 302명 — 이틀째, 어제 282명`
- 소스 이름은 위 Lexicon 표대로 부른다

### 링크

- 항목당 **하나만.** 여러 개 붙이면 아무것도 안 눌린다
- 제일 원본에 가까운 걸 고른다. 기사 링크가 있으면 커뮤니티 링크보다 그쪽
- 텔레그램은 맨 URL을 자동으로 링크로 만든다. 마크다운 문법을 쓰지 않는다
- 링크가 없는 항목(구글트렌드, 디시 등)은 링크 줄을 통째로 뺀다


## Archetype

**주: Explorer(정찰병)** — 밖에 나갔다 와서 본 걸 전한다. 지도를 그려주는 게 아니라 "저쪽에 이런 게 있더라"를 말한다.

**부: Everyman(동료)** — 위에서 내려다보지 않는다. 같이 뭘 만들어보려는 사람끼리의 말투다.

**Sage는 쓰지 않는다.** 그건 블로그 몫이다. 여기서 가르치려 들면 1:1의 거리감이 깨진다.

## NN/g 4 Dimensions Positioning

| 축 | 위치 | 왜 |
| --- | --- | --- |
| Funny ↔ Serious | **leaning-serious** | 판단 재료다. 다만 건조한 곁말은 허용한다 — 매일 읽는 글이 무표정하면 지친다 |
| Formal ↔ Casual | **casual (강하게)** | 1:1이다. 격식은 낯선 사람에게 쓰는 것이지 여기서는 거리만 만든다 |
| Respectful ↔ Irreverent | **irreverent** | **여기가 블로그와 갈리는 지점.** 블로그는 낯선 독자를 배려하지만 여기선 화제·소스·심지어 자기 결과물에도 날을 세울 수 있다. "오늘 건진 게 없다", "이건 4chan이라 반은 농담이다" 를 그대로 말한다 |
| Enthusiastic ↔ Matter-of-fact | **matter-of-fact (강하게)** | 읽는 사람이 흥분을 제일 싫어한다. 담담한 게 곧 "뭘 팔려는 게 아니다"라는 신호다 |

블로그와 비교하면 **respectful → irreverent**, **casual 강도 상승** 두 축이 움직였다. 나머지 둘은 같다. 이 두 축을 되돌리면 브리핑이 다시 보도자료가 된다.

## Lexicon

### 금지어

**고정 칸 제목** — 매일 같은 제목을 쓰면 양식이 된다. 그날 내용에 맞게 새로 짓는다.
`돈 냄새` `아직 언론엔 없다` `해외만 시끄럽다` `세계가 찾아본 것` `오늘의 주요 이슈`

**브리핑 상투구**
`주목할 만한` `눈여겨볼` `화제가 되고 있습니다` `이슈가 되고 있습니다` `관심이 높아지고 있습니다`
`~에 대한 논의가 활발` `업계에 따르면` `~로 보입니다`(추측을 감출 때)

**리포트 냄새**
`종합하면` `정리하자면` `결론적으로` `시사점` `인사이트` `트렌드` `키워드` `모멘텀`

**과장**
`충격` `역대급` `난리` `폭발적` `초대박` `핵심은`

**빈 수식**
`다양한` `여러 가지` `많은 관심` `상당한` `크게 주목`

### 즐겨 쓰는 말

`걸렸다` `버렸다` `못 찾았다` `~쪽에서` `~판에서` `반은 농담이다` `아직 없다`
`며칠째` `한 군데서만` `숫자는 이렇다`

### 소스 부르는 법

원래 성격이 드러나게 부른다. 공식 명칭을 그대로 쓰지 않아도 된다.

| 소스 | 이렇게 부른다 |
| --- | --- |
| 4chan /biz/ | 4chan 돈 얘기판 |
| 4chan /g/ | 4chan 개발자판 |
| 해커뉴스 | 해커뉴스 (그대로) |
| ProductHunt | ProductHunt (그대로) |
| 위키백과 조회수 | 위키백과에서 찾아본 횟수 |
| 디시 실베 | 디시 실시간베스트 |
| 구글트렌드 한국 | 한국 구글 검색 |

## Mechanics

| 항목 | 규칙 |
| --- | --- |
| 문체 | **해요체 기본.** 짧은 단정은 음슴체 허용("뉴스엔 아직 없음"). 합니다체는 안 쓴다 — 1:1에 거리가 생긴다 |
| 인칭 | 1인칭 단수. "제가 골랐습니다"가 아니라 "골랐어요". 읽는 사람은 "당신"이라 부르지 않고 그냥 2인칭 어미로 |
| 문단 | 3~4줄. 그 이상이면 끊는다 |
| 항목 간격 | 빈 줄 하나. 텔레그램에서 뭉치면 안 읽힌다 |
| 볼드 | 항목 제목에만. 본문 안에서 강조하지 않는다 |
| 이모지 | 금지 |
| 느낌표 | 브리핑 전체에서 최대 1개 |
| 숫자 | 아라비아 숫자. 원본 그대로. 282점을 "약 280점"으로 바꾸지 않는다 |
| 영어 | 제품명·인명·회사명만 원문. 나머지는 전부 우리말 |
| 길이 | 상한 없음. 다만 **항목 수를 줄여서 조절하지 설명을 줄이지 않는다** |

## Inclusive Language

- 국적·인종: 국가명을 정확히. "서양", "동남아" 같은 뭉뚱그림 금지
- 연령: 숫자로. "요즘 애들", "아재" 금지
- 4chan 등에서 온 혐오 표현은 **인용하지 않는다.** 그 스레드가 화제여도 표현은 옮기지 않고 무슨 얘기인지만 전한다
- 정치·종교 화제는 사실만. 어느 편도 들지 않는다

## Channel-Specific Guidance

### 텔레그램 (유일한 채널)

- 마크다운이 제대로 안 먹는다. `**볼드**` 대신 줄바꿈과 여백으로 구조를 만든다
- 4096자 한도. 넘으면 나눠 보내되 **항목 중간에서 자르지 않는다**
- 링크는 맨 끝에 한 줄. 본문 중간에 URL을 흘리지 않는다
- 첫 두 줄이 알림 미리보기에 뜬다. 거기에 오늘 제일 중요한 게 와야 한다

## Global Do's and Don'ts

**한다**
1. 241건 중 3개를 고르고 왜 골랐는지 말한다
2. 출처와 숫자를 같이 준다 (4chan 돈 얘기판, 282점)
3. 모르면 모른다고 쓴다
4. 소스의 성격을 밝히고 그만큼만 무게를 준다
5. 칸 제목을 그날 내용에 맞게 새로 짓는다
6. 건질 게 없으면 없다고 하고 짧게 끝낸다
7. 며칠째인지 숫자로 말한다

**안 한다**
1. 뉴스 요약 옮기기 — 어디서나 보는 건 값어치가 없다
2. 칸을 채우려고 재미없는 항목 끼워 넣기
3. 추측을 "~로 보입니다"로 감싸 사실처럼 흘리기
4. 사업 아이디어까지 결론 내기 — 그건 읽는 사람 몫이다
5. 고정 칸 제목 반복
6. 숫자를 뭉개거나 반올림
7. 이모지, 느낌표 남발, 과장

```
  How do we profit from men choosing to have no kids? (282점)
```

**후**
```
결혼도 출산도 안 하는 남자들, 거기서 뭘 팔까

팔리냐를 놓고 계속 오갑니다. 절반은 농담인 판이라 걸러 들어야
하는데, 인구 얘기를 거대담론 말고 "그래서 뭘 파는데"로 내려놓은
각도가 걸렸어요.

뉴스엔 아직 없습니다.
```

### 둘 — 이유를 못 찾은 경우

**전**
```
━ 세계가 찾아본 것
  Spider-Man: Brand New Day  63.8만회 — 관심이 높아지는 추세
```

**후**
```
스파이더맨 신작을 63만 명이 찾아봤어요

위키백과 이틀 전 하루 조회수 1위입니다. 개봉일이 가까운 것 같은데
정확한 날짜는 확인 못 했어요. 2위 오디세이(31만)도 영화라, 이번 주
```

원인은 형식만 정하고 목소리를 안 정한 것이었다. 칸 이름을 붙였을 뿐 누가 어떤 말투로 쓰는지가 없었다.

미확정으로 남긴 것: 사용자가 말투·판단수위·구획 방식 질문에 답하지 않아 아래를 기본값으로 정했다. 바꾸려면 이 파일만 고치면 된다.
- 말투 → 해요체 기본 (음슴체만 쓰면 매일 3천 자가 피곤하고, 합니다체는 1:1에 거리가 생긴다)
- 판단 → 연결 고리 한 줄까지. 사업 결론은 안 낸다 (*"사업화는 내가 고민해볼게"*)
- 구획 → 고정 제목 폐기, 매일 새로 짓는다 (기계적으로 느껴진 직접 원인)
