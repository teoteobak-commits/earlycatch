# vidiq 기반 주간 리서치 (2026-08-05 ~ 08-06, 중단)

해외 숏폼 포맷 중 국내에 없는 것을 매주 찾던 루틴. **vidiq 크레딧을
K-한류(kpop_kit_factory)에 몰아주기로 하면서 중단했다.**

중단 사유는 데이터 품질이 아니다. 오히려 잘 돌았다 — Be Kind 를 3주
추적으로 걸러냈고, 계측기 오류도 스스로 잡았다. 문제는 **찾은 키워드를
살 사람이 없었다는 것**이다. 크몽은 심사 중이었고 블로그는 색인도 안 됐다.

## 여기 남겨둔 이유

이 두 지시서에는 하루 걸려 알아낸 것들이 박혀 있다. 다시 만들 일이
생기면 이걸 먼저 읽는다.

- **git push 는 개인 토큰(PAT)으로 안 된다.** 프록시가 GitHub 쓰기를
  가로막고 Claude GitHub App 만 통과시킨다. PAT 세 형식 전부 403 이었고
  REST Contents API 와 GitHub MCP 도 같았다.
- **계측기를 바꾸면 안 된다.** 같은 밈이 vidiq 검색에서 18,651,
  트렌딩 피드에서 728,184 로 나왔다. 다른 자로 잰 값을 같은 계열에 넣으면
  폭락한 것처럼 보인다. 못 재면 null 이다.
- **초안은 텔레그램 문서로 보관한다.** 공개 저장소라 발행 전 원고를
  올릴 수 없어서, sendDocument 의 file_id 를 상태 파일에 적어두고
  승인되면 되받는 구조를 썼다.
- **텔레그램 .md 미리보기는 한글이 깨진다.** 문서는 기계용, 본문
  메시지는 사람용으로 따로 보낸다.
- **승인 키워드에 "승인" 이라는 글자를 쓰면 안 된다.** 같은 봇을 쓰는
  쇼츠박스 루틴이 그 단어를 자기 신호로 잡아 스레드에 자동 게시한다.
  그래서 `TEO발행` 을 썼다.
